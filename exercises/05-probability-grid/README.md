# 05 · Probability Grid — 学习 SQIA 音序器

学习 [SQIA](https://sqia.serezhaok.com/) 的公开前端机制，独立实现一个双轨概率步进音序器，理解**循环、强弱、概率与音色怎样共同形成音乐**。依据为当时检查的[公开代码](https://sqia.serezhaok.com/assets/index-Nmu30zQ9.js)及 Sound 截图；本项目使用原生 Web Audio，音色与参数不保证复现原站。

## 版本与使用

- [0.1](0.1/index.html)：基础音序规则，固定正弦 / 三角短音，保留作对照。
- [0.2](0.2/index.html)：当前版本；相同音序规则，增加五种音色和空间效果。

直接打开页面即可离线使用。拖动绘制，每轨可选音色、静音、随机和清空；擦除清除 2×2 格子。BPM、根音、音阶可实时调整。输入种子按 Enter 重新生成并播放，「换一版」使用新种子。停止后重播从头开始，图案保留；切到后台自动停止，刷新不保存。

## 核心规则

| 项目 | 规则 |
| --- | --- |
| 网格 | 每轨 16 行 × 12 列；行是时间，列是音高，同一行可多音触发 |
| 时钟 | 两轨同步循环，每步 `60 / BPM / 4` 秒；默认 120 BPM，每轮 2 秒 |
| 音高 | 沿选定音阶排列，默认 A minor、起音 A3；支持 minor / major / dorian / penta / phrygian |
| 强度 | 0 不响，1 每轮触发；中间值的触发概率为 `0.35 + 0.65 × 强度` |
| 力度 | 成功触发后为 `强度 × uniform(0.72, 0.98)`；例如强度 0.45，出现概率 64.25%，力度约 0.324–0.441 |
| 绘制 | 中心写为 1，根据指针偏移向最多三个邻格扩散，系数 0.9；重复绘制只提高强度 |
| 随机图案 | 先清空，每行 42% 概率放一个随机音，成功后 25% 概率再放一个；中心强度 1，上下左右 0.45，不越界 |
| 复现 | 图案、每轨触发、音色及素材随机流分离；相同种子、图案与操作顺序可复现，静音不扰动另一轨的音符序列 |

播放过程是：**读当前行 → 概率判断 → 计算音高与力度 → 发声 → 下一行 → 循环**。「随机」改变图案；播放概率只决定既有弱点这轮是否出现。格子规定起音时刻，尾音可以跨越多步。

## 为什么听起来更有音乐性

用户反馈 05 比 04 · 0.5 好听很多。以下是基于机制的解释，未经控制变量试听，不能确定各因素的贡献：

- **重复提供记忆**：固定图案不断回来，耳朵可以建立期待。
- **变化保留参照**：强点维持骨架，弱点时有时无，让同一段内容每轮略有不同。
- **强弱形成主次**：弱点既少出现，也更轻；邻格扩散把孤立音变成带陪衬的小片段。
- **音阶约束随机范围**：音符有共同调性感，但不保证所有组合都悦耳。
- **声部与尾音增加层次**：双轨、多音、变化的包络及空间效果，让离散音符形成连接；过密也可能混浊。

[04 · 0.5](../04-wfc-loom/0.5/README.md) 的 16 格是持续补新的未来窗口，力度固定，四音记忆还受休止与硬约束影响；05 的 16 格是反复返回的图案。主要启发是**稳定骨架上做局部变化**，不是算法越复杂越好听，也不能把音色带来的提升全部归因于音序规则。

## 五种 Sound（0.2）

点击每轨音色名称选择，默认 REVERIE + MACHINE。切换保留图案，旧尾音继续衰减。

| 音色 | 本项目的实现 |
| --- | --- |
| REVERIE | 失谐双振荡器、概率 FM / 泛音、0.7–2.9 秒变化包络 |
| KALIMBA | 正弦主体与快速衰减的非整数泛音，近似木质拨弦 |
| RHODES | FM 电钢琴、衰减调制量、tremolo 与合唱 |
| ACID | 低两八度锯齿 / 方波、共振滤波包络与力度重音 |
| MACHINE | 按音级选择合成低鼓、通鼓、军鼓 / 拍手和踩镲 |

效果链包含每轨滤波、合唱、合拍延迟和混响，再经过高通、压缩、总增益。混响脉冲本地生成；两轨延迟分别为 3 / 2 个十六分音符。参数见 `0.2/audio.js`；末级为压缩器，不是严格限幅器。

## 实现与验证

`sequencer.js` 管音乐规则，`audio.js` 管音色与调度，`app.js` 管交互。每 25ms 预排未来约 120ms，画面跟随音频时钟；编辑对已预排事件不生效。保留最多 40 组活跃单音，超限淡出最早声部；停止淡出后关闭上下文，异步启动有代次检查。统一接口为 `window.exercise.activate()` → `{schedule, end, deactivate}`。

在本练习目录运行 `node tools/check.cjs 0.1` 或 `node tools/check.cjs 0.2`；末尾可加音色 ID（如 `rhodes`）单独测试。

已通过语法及离线测试：概率、种子复现、五种音色调度、切换、变速、重启和节点清理。测试使用虚拟时钟与音频桩；尚未完成代理侧浏览器交互验收、实际波形测量及 SQIA 音频 A/B。用户自行试听，不等于原站音色已精确复现。
