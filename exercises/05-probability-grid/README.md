# 05 · Probability Grid

当前入口：[0.2](0.2/index.html)。双轨概率网格音序器，使用原生 Web Audio；无需构建、CDN 或外部音频素材。音序逻辑与声音设计分开，方便学习与版本对比。

## 版本

| 版本 | 内容 | 状态 |
| --- | --- | --- |
| [0.1](0.1/index.html) | 基础音序规则，固定正弦 / 三角短音 | 保留，不将 0.2 的声音改动回填 |
| [0.2](0.2/index.html) | 相同音序规则，五种独立音色、每轨 Sound 面板、合唱 / 延迟 / 混响 | 当前版本 |

## 运行与操作

直接打开 `0.2/index.html`，也可从仓库首页进入。默认 120 BPM、A minor、种子 `grid-05`；轨道 01 为 REVERIE，轨道 02 为 MACHINE。

- 共享播放按钮开始 / 停止。停止后复位，再播放从第 1 步开始，手绘图案保留。
- 网格纵向是 16 个时间步，横向是 12 个音阶位置。点击或拖动绘制，切换「擦除」后清除 2×2 格子。
- 每轨顶部的音色名称打开 Sound 面板；两轨可以选择同种或不同音色。选中项显示勾选，支持 Escape、关闭按钮和点击遮罩关闭。
- 播放中切换音色不清空图案；已预排约 120ms 内的音符可能使用旧音色。旧尾音继续衰减，共享轨道效果随新音色调整。
- 每轨可静音、随机或清空。静音停止后续触发，已发出的尾音不会立即截断。
- BPM（40–240）、根音和音阶可以在播放中修改，已预排事件保持原参数。
- 种子输入后按 Enter：重新生成两轨图案并从头播放。共享「换一版」产生新种子；单轨「随机」只重画该轨，不重启时钟。
- 空格控制播放 / 停止；输入框、按钮和 Sound 面板内不触发全局空格快捷键。
- 切到后台或离开页面自动停止。刷新恢复默认状态；当前没有项目存储或音频导出。

## 音序规则（两版共用）

1. 两轨共享 16 步循环，每步 `60 / BPM / 4` 秒。120 BPM 时每步 0.125 秒，每轮 2 秒。
2. 12 列是音阶中连续 12 个音，不是十二个半音。默认 A minor 从 A3 开始；支持 minor、major、dorian、penta、phrygian。MACHINE 用计算出的音级选择鼓类，ACID 再降低两八度。
3. 每格强度为 0–1：0 静音，1 必触发，中间值的概率为 `0.35 + 0.65 × 强度`。成功触发后的力度为 `强度 × uniform(0.72, 0.98)`。
4. 绘制只提高强度：中心写为 1，根据指针偏移向最多三个邻格扩散，弱点系数 0.9。擦除在边缘向内约束到合法 2×2 区域。
5. 随机生成先清空，每行有 42% 概率放一个随机音高，成功后另有 25% 概率再放一个。每个印章的中心为 1，上下左右为 0.45，不越界。邻行印章可让未直接抽中的行也有弱点。
6. 图案、每轨触发判定、每轨音色、噪声及混响使用分开的种子随机流。触发流每格固定取两个随机值，空格子和静音轨也推进，因此静音不扰动其他轨道的音符序列。
7. 同一初始种子、图案与操作顺序可复现；播放中人为切换的时机也是演出条件。随机图案或音色变化不会消耗音符触发的随机流。

## 五种 Sound（0.2）

| 音色 | 声音结构 | 当前实现范围 |
| --- | --- | --- |
| REVERIE | 双振荡器失谐，概率 FM / 八度泛音，变化的低通与声像 | 起音约 12–230ms，总包络约 0.7–2.9s，漂浮长尾 |
| KALIMBA | 正弦主体、2.76 倍频快速衰减泛音、5.4 倍频弱泛音、低通 | 约 0.48–1.15s 的木质拨弦近似；不是物理建模 |
| RHODES | FM 电钢琴、快速衰减的调制量、弱倍频、tremolo | 约 1.1–2.35s 包络，3.8–6.2Hz 振幅调制与合唱 |
| ACID | 低两八度锯齿 / 方波、共振滤波包络、力度重音、额外低通 | 约 0.16–0.42s 包络，居中声像；没有实现滑音或完整 303 电路模型 |
| MACHINE | 低鼓 / 通鼓、军鼓 / 拍手噪声、踩镲 | 根据 MIDI 音级分组，随机衰减与滤波，全部本地合成 |

名称及音色类别对照用户提供的 SQIA Sound 截图。代码和参数为本项目独立实现；未完成与 SQIA 的音频 A/B，不能称为同音色复刻。

## 效果链与调度

0.2 的单音包络与滤波 / 声像进入每轨效果链：干声与并行合唱、合拍延迟、立体声卷积混响 → 38Hz 高通 → 总线压缩 → master（+6dB，淡入淡出）→ DynamicsCompressor（−1dB 阈值、20:1）→ 输出。最后一级是压缩器，不是严格的 brickwall limiter。

- 五种音色各有滤波范围、混响发送、合唱量和延迟湿度；播放循环起点平滑变化部分参数。
- 混响脉冲由独立种子生成，长度 4.8s、约 23ms 预延迟；湿路高通 260Hz、低通 5400Hz。
- 轨道 01 / 02 的延迟固定为 3 / 2 个十六分音符，跟随 BPM；反馈范围 0.22–0.43。轨道编号仍决定延迟节拍与左右倾向，不决定音色。
- 合唱采用 14ms 延迟、±3ms 调制，湿度按音色配置；ACID 的合唱量为零。
- 最多保留 40 组活跃单音；超过时以短淡出退掉最早声部，退场过程可能短暂重叠。各声源结束后断开节点。
- 每 25ms 预排未来约 120ms，以 AudioContext 时间发声；画面到对应音频时间才更新。
- 停止先取消调度器和动画，再淡出 70ms，随后关闭上下文。异步启动有代次检查，迟到引擎会销毁；重复 `schedule()` 不安装第二个调度器。

统一接口：`window.exercise.activate()`，返回 `{schedule, end, deactivate}`。音序模型不依赖音频设备或 DOM。
