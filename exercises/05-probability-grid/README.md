# 05 · Probability Grid

浏览器生成式音序实验，使用原生 Web Audio。0.1–0.2 学习 SQIA 的概率网格，0.3 引入 SQNCR 的共享卷帘和和声取音思路。是独立实现与机制适配，不保证复现参考应用的音色、构图或听感。

## 版本与运行

- [0.3](0.3/index.html)：当前版本，五声部共享卷帘、显式概率/力度、和声发展。
- [0.2](0.2/index.html)：双轨 16×12 概率网格，五种音色可二选，保留作对照。
- [0.1](0.1/index.html)：双轨基础音序与短音。

直接打开对应页面即可离线运行。空格播放/停止；输入种子按 Enter 重新生成并播放，「换一版」生成新图案。停止后从头播放，刷新不保存；切到后台自动停止。

## 0.3 时间与网格

参考 SQNCR 的常量：基础画布 1920×1080、网格单位 20，即 96×54 细格；普通声音对象占 2×2 细格。本项目用 **48 个时间位置 × 27 个音阶位置**实现交互格，格内再绘制细分线，整体保持 16:9。不是 SQNCR 完整布局引擎的移植。

横向从左向右扫描，四段，每段两个小节。一个交互步是八分音符，`60 / BPM / 2` 秒；每小节六步（3/4），全幅八小节、24 拍，120 BPM 时 12 秒。段首虚线、小节首弱分隔；已撤销 32/64 选择。

纵轴是选定音阶的 27 个位置；默认 A minor，支持 minor / major / dorian / penta / phrygian。坐标储存原始绘制音级，显示/演奏时再应用和声映射。

## 0.3 音乐实现来源与边界

**当前是原本的概率音序系统 + 部分 SQNCR 机制，不是完整采用或移植 SQNCR。** 原有音色引擎继续发声，原有概率散布产生初始图案；SQNCR 参考主要作用于和声约束和时间结构。

| 部分 | 当前来源与实现 |
| --- | --- |
| 音色、合成和效果 | 沿用 0.2 五种 Sound 与原生 Web Audio 引擎；并非 SQNCR 的乐器实现 |
| 初始音符生成 | 本项目按声部概率散布音符；尚未采用 SQNCR 的乐器专属节奏模板 |
| 触发概率与力度 | 从本项目原有机制扩展为独立字段；力度仍带独立演出随机变化 |
| 和声推进 | 参考 SQNCR City 的和弦级数候选及筛选思路 |
| 贝斯、铺底取音 | 参考和弦音取音机制，适配给 ACID / REVERIE；这两个角色分配是本项目的选择 |
| 旋律强拍修正 | 参考就近落到当前和弦音的机制，适配给 RHODES / KALIMBA |
| 时间结构 | 根据 SQNCR 默认网格及四个重复段适配为四段、八小节；并非其完整分段事件生成器 |

尚未接入：SQNCR 的乐器专属节奏规则、hook/core/interlock/float 动机轮廓生成、节奏填充、声部分段出入掩码、录音切片编排，以及完整风格系统。

因此不能把当前音乐听感全部归因于 SQNCR，也不能以“网格已经对齐”推断作曲算法已经对齐。后续若继续采用其机制，应逐项核实来源、写清适配差异并验证；不要自行添加演变算法后称为 SQNCR 的方式。
## 0.3 声音与音乐规则

| Sound | 形状 | 合成与角色 |
| --- | --- | --- |
| REVERIE | 圆 | 失谐振荡器与变化尾音；适配为和声铺底 |
| KALIMBA | 菱形 | 木质拨弦近似；旋律声部 |
| RHODES | 方形 | FM 电钢琴；旋律声部 |
| ACID | 三角 | 低音锯齿/方波与滤波包络；适配为贝斯 |
| MACHINE | 十字 | 按音级分配合成鼓；保持原鼓音级 |

五种 Sound 同时可用，选择 Sound 后绘制；同格允许叠加，静音/清空只影响当前 Sound。直接写当前格，不沿用 0.2 的邻格发声扩散。

概率与力度独立：绘制概率 100% / 75% / 50%，力度 100% / 80% / 45%。触发后实际力度仍为 `设定力度 × uniform(0.72, 0.98)`。初始图案由各声部独立种子流生成：每步 MACHINE 55%、其他 27% 概率放音；ACID 使用低四个音级，其他取全部音级；力度 0.8，第 `step % 4 === 0` 的事件概率 1，其余 0.5。这套初始散布规则不是 SQNCR 的节奏模板算法。

和声参考 SQNCR City 的 `turn/turnMajor` 候选、`Sw/If` 推进、`Of` 和弦取音和 `sung/Ew` 强拍修正。每六步换和声，八个位置后循环：REVERIE/ACID 根据原始音级映射到和弦音序列；RHODES/KALIMBA 在每小节首步就近修正为和弦音，其余保持原始音高。MACHINE 不跟随和声。当前不是无限改写旋律，也没有完整复刻 SQNCR 的动机轮廓、节奏模板或声部分段掩码。

音符谱、概率、音色、噪声/混响随机流分离。静音不改变其他声部的演奏序列；视觉不消耗音乐随机流。已有预排音符不受随后编辑影响。

## 0.3 当前图形排列逻辑

**主音**：时间决定横坐标，和声映射后的音级决定纵坐标；形状/颜色标识 Sound，大小表示设定力度，透明度表示概率。实际触发时闪白并用本次实际力度设置尺寸，下一步恢复。多个音落同格时仍由格内 flex 自动排列，没有专门的碰撞避让或整体构图。

**静态陪衬**：每个主音依次检查上、下、左、右及部分斜邻格。数量为 `3 + round(力度 × 3)`，权重为 `力度 / (1 + 横向距离 + 纵向距离)`，距离越远越弱。真实音符优先，陪衬不占有主音的格子；多个陪衬争同格时取权重较强的一个。它们是视觉投影，不是新增弱音，不参与发声。

**发声反馈**：从真实音符事件的最终音高和实际 velocity 出发，在附近空格显示点/块，再驻留淡出。数量 `3 + round(velocity × 5)`，寿命至少 550ms、随拍长变化；最多 160 个元素，结束移除、停止清空。减少动态效果偏好关闭这层反馈。

**与参考的区别**：0.2 邻格小圆是实际参与演奏的弱音；0.3 陪衬只做视觉。SQNCR 有图形占地、布局策略、邻接与不同尺度的对象组织；当前仅实现音高落格和固定邻域扩散。网格尺寸对齐不等于构图算法对齐。用户已反馈当前形式简陋，视觉设计尚未验收，不能称为已复现 SQNCR。

## 界面与播放性能

矩阵为主要视觉区域，顶部采用紧凑参数栏、Sound 标签和编辑参数；图例/帮助折叠到矩阵下方。窄屏横向滚动。

播放头是独立覆盖层中的细竖线，使用 Web Animations 线性连续扫幅；音频位置负责循环、BPM 变化和超过 100ms 偏差时校准。格子几何集中缓存，resize 后失效；每步不重建整张矩阵，只更新触发反馈。覆盖层必须绝对定位，不能参与 Grid 自动排布。

音频每 25ms 预排约 120ms；保留最多 40 组活跃单音，超限释放最早声部。停止淡出后关闭上下文，异步启动有代次检查。接口：`window.exercise.activate()` 返回 `{schedule, end, deactivate}`。

### 当前配色（2026-10-30）

采用墨蓝黑背景，每个 Sound 固定色系，亮色用于触发与部分陪衬、深色用于短暂色块：REVERIE 电蓝 `#5487ff`，KALIMBA 珊瑚 `#ff765e`，RHODES 柠黄 `#e6ed59`，ACID 紫罗兰 `#b78aff`，MACHINE 青色 `#45d9bb`。参考 SQNCR 每个色系有深浅/对比层次的思路，未照用其色板。概率仍影响主音透明度，但下限由 .25 提至 .45，避免整幅发灰；陪衬亦提高可见度。发声反馈为同色系亮色，不再统一闪白。页面图例中的“闪白”应随之改为“亮起”。配色尚待用户视觉验收。

五声音阶：原 penta 保留内部 ID，界面明确为 PENTA MINOR（0,3,5,7,10）；新增 PENTA MAJOR（0,2,4,7,9），使用英文显示。大调五声采用大调和声候选，所有最终音高仍约束在所选五声音阶。音程、27音级映射与48步和声边界检查通过。
