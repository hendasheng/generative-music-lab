▶ 机制与循环
机制：固定音符独立循环：种子决定周期、初始相位与力度呼吸的起点；钢琴时长参考采样衰减，Drone 时长由包络与留白计算。周期和时长在一场中保持稳定，循环持续错位，力度跨多轮缓慢起伏。
灵感：Tero Parviainen 的 JavaScript Systems Music 中，Music for Airports 使用不同循环周期的单音 tape loop；本练习使用采样钢琴与 Drone，并加入音色时长与力度呼吸。
