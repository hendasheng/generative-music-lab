03 · Phase Loops 0.3

独立周期持续错位，让音符的相遇关系生成旋律与和声。
点击播放开始。每层环带是一条循环，前端经过固定竖线时发声。
▶ 机制与循环
机制：固定音符集合不变，但每个音都有自己的周期、时值和初始相位。由于周期彼此错开，任何两个音的先后顺序和重叠关系都会慢慢改变。
灵感：Tero Parviainen 的 JavaScript Systems Music 中，Music for Airports 的核心是多个不同长度的单音 tape loop；这里先沿用 02 的采样钢琴，方便比较两种生成机制。
