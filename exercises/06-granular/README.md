## 0.1 · 基础实现

直接打开 [0.1/index.html](0.1/index.html)，无需构建或联网。内置本地合成的八秒谐波素材，也可导入浏览器支持的音频文件（最大 40 MB，使用前 30 秒、最多双声道）。文件只在本地解码，不上传。

播放后拖动波形选择取样中心。可调整位置、粒子长度 15–1000ms、密度 2–60 颗/秒、音高 ±24 半音、位置散布、立体声散布和倒放概率。绿粒子正放，橙粒子倒放；横条是该粒子读取的源音频区间，亮点按实际播放速率移动，上下位置表示左右声像，亮度按 Hann 包络变化。提前调度的粒子到发声时间才显示。

种子控制位置、声像与倒放抽样。停止后重播重置随机流；相同音源、参数及种子可复现随机序列。实时操作的结果还取决于操作时间。「换一版」只换随机序列，不改参数和音源。切到后台自动停止。

## 实现约定

- `engine.js`：纯粒子计划、独立种子随机流、原生 Web Audio 与生命周期。每 25ms 预排未来 120ms；遇到主线程长暂停，跳过过期时刻，不补发积压粒子。
- 每颗粒子：BufferSource → Hann 包络 → StereoPanner → 总线。时长以输出秒数计，源读取长度乘播放速率，取样区间限制在音源边界内；倒放使用反向副本。
- 预计重叠量 `density × duration` 控制粒子增益，最多 192 个待播放/活动粒子；onended 清节点。母带 +6dB，35–40ms 淡出入，末级压缩器用于缓和峰值，不是严格限幅器。
- 声音/画面共享音频时钟；视觉不消耗音乐随机数。改变参数只影响之后计划的粒子，最多约 120ms 调度延迟。
- 停止取消调度、淡出后清所有节点并关闭上下文。异步启动和导入分别带代次取消检查。`window.exercise.activate()` 返回 `{schedule, end, deactivate}`；schedule 重复调用幂等，end 后重播需重新 activate。
- `app.js`：音源管理、参数与 Canvas 显示；播放与种子沿用公共组件。

0.1 保留基础颗粒声音，不加入混响、XY 宏、麦克风录音或导出。后续版本可逐项扩展。

## 0.2 · XY 音色联动（保留基线）

入口：[0.2/index.html](0.2/index.html)。保留 0.1 独立文件。波形和音源导入继续保留，增加 XY 操作面板；拖动松手锁定，方向键微调，Shift 加大步长，Home 或「回到中央」复位。旋钮始终表示基础值；中央与 0.1 的粒子随机序列一致，宏调制使用另一条种子随机流。

四角强度由双线性角权重减去中心基准后归一化得到，因此中央全部为零，相邻区域可混合。

| 角落 | 最强时的映射（相对基础值） |
| --- | --- |
| Reverse | 剩余正放概率中 85% 转倒放；长度 ×0.55；45% 概率升八度 |
| Chorus | 长度 ×2.5；密度 ×0.75；逐粒子 ±30 cents 失谐；中心以 14 秒周期漂移 ±12% 音源长度 |
| Gater | 密度 ×1.8；固定 120 BPM 十六分音符音量门，50% 开门占比，最大衰减 95%，5ms 边沿平滑 |
| Scatter | 位置散布增加 ±25% 音源长度（上限 ±50%）；密度 ×1.5；从 0/0/+7/-7/+12/-12 半音抽样 |

没有混响。音量门作用于粒子总线，粒子可视亮度乘同一音频时间上的门控增益。倒放、长度与位置继续从实际已排程事件读取；波形上的竖线及散布带显示当前宏调制中心/范围。UI 操作对未来约 120ms 已排程事件无追溯作用。

验证：`node tools/check.cjs 0.2`，包含中央恒等、100 组 XY/时间组合、四角映射、短素材边界、节奏门相位以及原有调度/清理测试。声音审美与最终听感仍需实际试听。

浏览器验收：0.2 页面加载、XY 方向键更新、中央复位、播放/停止状态切换通过，检查时没有控制台警告或错误；未进行实际听感评估。


0.2 参数联动显示：参数主数值实时显示 XY 调制后的结果，受调制时高亮；小字显示基础值，滑杆继续编辑基础值，回到中央恢复。音高为逐粒子随机，因此显示可能范围，包含 Reverse 的八度、Scatter 的音程和 Chorus 的微量失谐，不以假平均值冒充实际音高。显示不消耗音乐随机流。


0.2 UI：采用暖灰机身、石墨色波形屏、紧凑编号参数分区及少量橙色操作强调；取消绿色发光。宽屏波形与 XY 并排，窄屏上下排列；浅灰粒子正放、橙色倒放。仅改视觉，音频规则不变。


0.2 滑块同步修正：滑块与主数值一起显示 XY 调制结果；长度/密度滑轨覆盖宏调制的完整范围，避免超过基础上限后卡在轨道终点。手动编辑通过反算更新基础值，避免重复叠加调制；拖动期间不让动画抢动滑块。随机音高滑块表示所显示范围的中心，小字继续保留基础值。


XY 拖动恢复：新的主指针按下可覆盖残留拖动状态；窗口级 move/up/cancel 兜底，失焦、切后台、鼠标无按键时释放状态；捕获失败不阻断本次移动。禁止 XY 文字选择与原生拖拽，固定效果说明高度，避免文案换行使操作区尺寸变化。


0.2 滑块拖动修正：此前滑轨仅 3px 高，落点偏到邻近可选中文字（标签、数值、编号）上再拖动会触发浏览器原生文本拖拽，光标变为禁用符且拖拽期间滑块失灵、状态可能卡住。现整个演奏面（乐器区、页脚、注释）禁用文本选择并拦截页面原生拖拽（本页无放置目标，导入仍走点击）；滑轨命中区加高到 22px、视觉仍为居中 3px 线；窗口失焦或切后台时清除滑块编辑状态，避免丢失的 pointerup 冻结某格显示。头部种子输入不受影响，仍可正常选取文字。


## 0.3 · 位置 × 质感（当前版本）

入口：[0.3/index.html](0.3/index.html)。直接打开即可，无需构建或联网。0.1 基础版和 0.2 四角效果宏完整保留作为对照。

### XY 与手动控制

左右寻找片段，上下改变播放质感。横轴选择 0–100% 的取样中心；纵轴从上到下将位置散布从 0 增加到 ±50%，并逐渐提高倒放概率。

倒放映射为 `(2 × spray)^2.5`：顶端正放，中点约 18% 倒放，底端纯倒放。上半区以正放为主，下半区反向质感明显增强。Reverse 滑块可独立覆盖当前概率，不改变 XY 点；纯横向移动保留覆盖，下次纵向变化重新接管。

XY、滑块、波形和音频引擎使用同一组实际参数，数值与滑块同步更新。波形拖动仅改变取样位置；位置和散布滑块同步 XY 点，散布滑块单独操作时保留当前倒放概率。方向键微调 XY，Shift 加大步长；XY 获得焦点时空格切换自由流动。

本版不使用 0.2 的四角效果宏、随机音程、自动失谐及节奏门。粒子按实际音频时钟显示：浅灰正放、橙色倒放，阴影表示起点散布范围，读取区间仍受素材边界与音高/时长约束。轨迹录制不在本版范围内。

### 自由流动

从开启瞬间的当前值开始，位置、散布、长度、密度和立体声散布分别使用独立种子随机流，以不同幅度和周期生成目标，通过五次平滑曲线连接。音高始终不变。

| 参数 | 每段目标的游走时间 |
| --- | --- |
| 取样位置 | 6–13 秒 |
| 位置散布 | 9–18 秒 |
| 粒子长度 | 7–15 秒 |
| 密度 | 5–11 秒 |
| 立体声散布 | 11–21 秒 |

倒放跟随纵轴的散布曲线，不单独随机游走。如果开启前手动设置了倒放，用 4 秒平滑过渡到映射曲线，避免突然跳变。`flow.js` 的随机流独立于粒子抽样；相同起点、种子与操作时序可以复现。

25ms 控制定时器独立于画面刷新推进；卡顿时限制单次推进量，不追赶长时间积压。关闭后保留当前值。手动操作 XY、波形取样位置或任意参数滑块（包括音高）立即关闭整个自由流动，按钮同步关闭，松手不会自动恢复；键盘调整同样关闭。停止播放、导入素材和切到后台会关闭流动并清理定时器。未播放时也能开启观察参数变化。

### 界面布局

延续暖灰、石墨色与少量橙色强调的硬件风格。01 SOURCE 与 02 SAMPLE FIELD 是平级两栏，各自包含标题、操作面和读数。两栏共享 100px 标题行、300px 操作面及 48px 读数行，波形与 Pad 顶部和底部对齐。窄屏上下排列，操作面统一 235px。

参数区独立位于两栏下方，DOM 顺序与键盘焦点顺序一致：

- 第一排三等分：取样位置、位置散布、倒放概率，对应 XY 控制。
- 第二排四等分：粒子长度、密度、立体声散布、音高。
- 窄屏前三项各占一行，其余按两列排列，保持控制分组边界。

沿用加大的滑块命中区、指针捕获失败兜底、失焦释放和禁止原生文本拖拽处理。

### 0.3 麦克风采样

音源区新增「录制采样 · 30s」。点击后停止合成器与自由流动，再请求麦克风；按钮显示录制秒数，可随时提前停止。30 秒自动结束，随后本地解码并载入波形，点击播放使用新采样。最大载入长度仍严格裁为 30 秒；浏览器定时器暂停可能使实际采集超过该时间，因此不是硬实时设备限时。录音小于 0.25 秒或失败时保留旧素材。

等待权限可点击取消；录制中禁用播放和其他音源入口，切后台/离开页面取消录音并释放所有麦克风轨道。取消后的迟到授权也会立即释放轨道。没有实时麦克风监听，不自动播放录好的素材。录音只在本地内存中，未添加下载或持久保存。

使用浏览器 MediaRecorder 支持的格式（优先 Opus WebM/Ogg，再 MP4，否则默认格式），请求关闭降噪、自动增益和回声消除，以保留采样质感。权限与设备失败显示具体提示；若本地文件方式不可用，通过 localhost 或 HTTPS 打开并允许麦克风。API 依据：[getUserMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia)、[MediaRecorder.stop](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder/stop)。

`node tools/record-check.cjs` 离线验证手动停止、30 秒定时结束、等待权限取消、拒绝权限、录音取消、过短拒绝及轨道/计时器释放。引擎原回归也通过；未进行真实麦克风录制、浏览器编解码兼容性及录音听感验收。

录制时波形屏显示橙色实时麦克风波形（REC / LIVE INPUT），由 AnalyserNode 读取 2048 点时域数据，沿用现有画面刷新循环；不是整段录音的累计波形。停止并解码成功后切换为完整采样波形；取消/失败恢复旧波形。分析节点不连接扬声器，结束后断开节点并关闭专属分析 AudioContext。离线桩增加波形读取和分析上下文清理检查；真实设备显示尚需浏览器验证。


### 0.3 听感调整：采样补偿、空间与输出

对照 [Granula 源码](https://github.com/serezhaOk/Granula/blob/db1191e8ad404d81fc20e9a69d5e7a822413198f/index.html) 后独立实现以下调整，未复制其源码或音频素材。参考提交 `db1191e8ad404d81fc20e9a69d5e7a822413198f`；仓库公开源码不代表开源许可。

- 轻采样在音频总线补偿，源 buffer 不变：统计全部声道 RMS 和峰值，目标 RMS 0.16，峰值预算 0.85，最多放大 4 倍（约 +12dB）；RMS 低于 0.001 不放大，已经响的素材不衰减。补偿使用整段素材统计，不会把局部静音自动拉满，也不保证不同素材听感等响。
- 新增独立「03 / SPACE & OUTPUT」区：混响 0–100%，默认 30%；输出 −24 至 +6dB，默认 0dB（相对既有 +6dB 母带）。两者不受 XY 或自由流动驱动，手动操作仍关闭流动。
- 自行生成 4.5 秒双声道衰减噪声脉冲，前后平滑、低通平滑噪声；并行混响发送最大 0.8，干声保持，不是等功率干湿交叉淡化。无高八度层、不改变音高。停止时总干湿一起淡出清理，不保留后台尾音。
- 默认散布改为约 ±250ms：初始八秒素材 spray=0.03125；每次成功加载音源按时长重设 spray（最大 0.5），同步 XY。Reverse 保留当前值，下一次纵向手势重新接管。纵轴最大范围仍是 ±50% 素材长度。
- 发声间隔增加 ±10% 随机变化，使用独立 `seed + ':timing'` 流；粒子位置/倒放随机流不受其消耗影响。密度仍为平均速率的目标。

母带 +6dB、Hann 窗和按重叠数量的增益补偿保留。新信号链：粒子 → bus → 采样补偿 → 干声 / 卷积混响并行 → master 淡入淡出 → 输出旋钮 → compressor → destination。压缩器仍非严格限幅器。

离线检查新增静音不提升、增益上限、瞬态峰值预算、源数据不变、默认散布时长一致、调度扰动边界、脉冲有限值及所有新节点释放；录音回归通过。尚未进行本轮真实浏览器音频渲染与试听；默认混响和输出为首轮调音值，可按用户试听继续调整。


### 0.3 内置素材去噪与高八度空间层

移除内置 demo 中主动添加的 0.015 幅度白噪声，保留谐波与包络；混响返回加入 4.5kHz、Q=0.707 低通，减轻高频噪声感。用户导入/录音的原始素材不做去噪。卷积脉冲中的衰减噪声作为滤波响应保留，不是独立持续发声的噪声源。

在混响大于 0 时，每颗主粒子以 45% 概率附加 +12 半音粒子，独立 shimmer 随机流，峰值为主粒子 40%、目标长度 1.25 倍（受素材边界限制），继承倒放方向和声像。附加粒子仅送混响，并使用相同采样音量补偿；混响为 0 时不生成，湿声归零后不可听。主音高参数保持不变；因此先前“无高八度层”的说明由本节取代。粒子显示读取该声部事件，包含实际 rate/length，湿声尾音本身不逐粒子显示。所有声部共用 192 上限，停止清理新增节点。

### 0.3 原音与八度的音乐层次
