机制与转移
机制（对照 aisatsana 源码）：① 音符素材按八分音符网格量化 → ② 每 32 步切成一个乐句 → ③ 乐句序列喂给段落链训练转换概率 → ④ 当前段落内的音符相邻关系训练第二条链 → ⑤ 演出时两条链分别重组乐句顺序和句内音高。节奏位置、力度与演奏版本仍沿用 0.1。
0.4 视觉：节点（全部段落用过的音高）与边（全部出现过的转移）只建一次、永不重建。 连线的明度 = 转移概率：`walkNote` 是从当前音的后继里等概率挑一个（重复项就是权重）， 所以 from→to 的概率 = 出现次数 ÷ 该音后继总数；越常走的转移画得越亮。 属于当前段落的音高留在环上，其余音高收进下层、滑到某个在场节点背后被挡住； 变成乐句点时它从宿主背后一次弹出：起步很猛，临到落点单次过冲再收回； 每次换句所有点都会移动一段距离（环的相位与半径每句轻微改变）， 刚变成乐句点的点用“弹”、本来就是乐句点的点用平滑滑位； 每个点速度不同，而且允许飞到首音之后才落位。 连线也一起生长：一端刚变成乐句点的转移朝那个新点长过去（新点在起点端就从另一端长过来）； 两端本来就是在场的乐句点时，连线只是跟着点移动，不重新生长。 整段结构变化在首音那一刻开始，时长基准是本句内部第一个音程（首音 → 第二个音）： 于是变换跟着音乐发生（旧版落在“上一句尾音 → 本句首音”的空白里，那段区间没有新音，观感很干）。 所以不会出现“一条还没长完、另一条已经开始”。 转移被激活时不是整条变色，而是彩色沿曲线从起点走到终点，到达终点时箭头才亮起； 同一个音程同时决定三件事：彩色行进走多久、这个点从亮到暗用多久、箭头何时亮 —— 音密处一闪即暗、留白处余韵长（不是每个音都固定时长）。 只有被激活的连线才有箭头（行进中跟着彩色头部走、反向生长时慢慢掉头，走到终点后停在终点）； 常规连线不画箭头 —— 它的方向靠沿线灰度渐变读：起点端亮、终点端淡， 线越亮 = 该转移在马尔可夫链里概率越高。 换句时不是整体外扩，而是给在场节点一次切向抖动，位移沿连线传给邻居： 连线是铰链，弹因此是传开的。力度分两级：换句/段落切换抖得明显， 单个音符发声只是很轻地推一下。段落色逐帧插值，不在句界跳变。
环境层涟漪：birds 环境声响着的期间，画面上会时不时炸开一发 —— 主体不是圆，而是一群一边自转、一边往外游走的线：每根线绕自己的中心转，中心同时在慢慢漂走， 画出来是一小段扫过的弧（只留最近约 0.13 秒的轨迹）。另有偶尔才有的涟漪圈 （三成的一发完全没有圈；有圈时圆心也是偏出去的，不是同心）和几道向外飞散并变细的短痕。 每一发、每一个元素都不一样：线的数量（每发 7–16 根）、自转半径、转速、走多远、寿命、描边、 颜色逐项各取一份 —— 有的小步慢转、有的飞快甩出去，短的不到 1 秒就没了、长的能飘 4 秒多。 ★ 而且好几发会同时在场：一次"击发"有 45% 的概率不是 1 发、而是一簇 2–4 发 （在 1.1 秒内先后炸开，位置各不相同），所以画面上的节奏是"有时一声、有时几下发在一起"， 而不是整齐的一个接一个 —— 这样才对得上鸟叫本身忽大忽小、忽快忽慢的随机感。 出现是半径/长度从 0 长出来、消失是描边细到 0，全程不用透明度。 它只跟 birds 有关，颜色全部由当前段落色转出来（换段/切主题整组一起变）； 整体尺度仍由这一层的声音决定（`targetGain` → 大小范围、`fade` → 时间范围）； 落点铺满整块画面（在"安全区"里均匀抽，四周只留约短边 12% 的余量，`pan` 只是让落点整体偏一点）； 随机只在这个范围之内分配，不替代音乐决定的关系（判据见视觉规则 §15）。
参考出处：这个效果的形式借鉴自 okazz 的 p5.js sketch 「240809a」 （openprocessing.org/sketch/2326097， 许可 CC BY-NC-SA）—— 只借"旋转游走的拖尾线 + 减速外扩的涟漪圈 + 描边随生命变细"这三个动作， 没有复制它的任何一行代码（元素数量、颜色、随机、尺寸全部按本项目的规则重写）， 所以本仓库不会被它的 SA 条款传染。
调试图方便：按 s 键就手动来一发 —— 参数和落点都走真鸟叫那一套算法 （所以看到的就是真鸟叫时会看到的那一发），不用等；每按一下形态都不同（"第 N 下"可复现）， 而且不动用鸟叫那条随机流。见 DEBUG_BURST_KEY。
操作：点击画面隐藏 / 显示界面；按 s 手动来一发调试涟漪；按 f 全屏、再按一次退出。
与 01 的对照：01 是"从零生成"（和弦进行 + 动机发展）；这里是"记忆 + 重排"—— 音符 100% 来自素材，但顺序被概率重组，听感像"同一首曲子的不同演奏"。
钢琴音色：真实采样 vsco2-piano-mf（VSCO2 免费钢琴库，CC0），经 jsDelivr GitHub 镜像远程加载 （首次约 50MB，之后走浏览器缓存）；加载失败自动回退 FM 合成钢琴，不会卡死。
总音量：钢琴与环境层汇到同一条母带链（总增益 → 限幅 −1dB → 输出）， 所以要整体调响只改代码里那一个 MASTER_VOLUME_DB（dB）；限幅在最后一级，往上推不会削顶。 要单独调某一层，改它自己的增益（钢琴 volume、环境层各自的 targetGain）。
