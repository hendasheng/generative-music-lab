点击播放开始。日志会显示每次乐句转换（马尔可夫链的"行走"）。按 f 全屏。
机制与转移
机制（对照 aisatsana 源码）：① 音符素材按八分音符网格量化 → ② 每 32 步切成一个乐句 → ③ 乐句序列喂给段落链训练转换概率 → ④ 当前段落内的音符相邻关系训练第二条链 → ⑤ 演出时两条链分别重组乐句顺序和句内音高。节奏位置、力度与演奏版本仍沿用 0.1。
0.3 视觉：节点（全部段落用过的音高）与边（全部出现过的转移）只建一次、永不重建。 连线的明度 = 转移概率：`walkNote` 是从当前音的后继里等概率挑一个（重复项就是权重）， 所以 from→to 的概率 = 出现次数 ÷ 该音后继总数；越常走的转移画得越亮。 属于当前段落的音高留在环上，其余音高收进下层、滑到某个在场节点背后被挡住； 变成乐句点时它从宿主背后一次弹出：起步很猛，临到落点单次过冲再收回； 每次换句所有点都会移动一段距离（环的相位与半径每句轻微改变）， 刚变成乐句点的点用“弹”、本来就是乐句点的点用平滑滑位； 每个点速度不同，而且允许飞到首音之后才落位。 连线也一起生长：一端刚变成乐句点的转移朝那个新点长过去（新点在起点端就从另一端长过来）； 两端本来就是在场的乐句点时，连线只是跟着点移动，不重新生长。 整段结构变化在首音那一刻开始，时长基准是本句内部第一个音程（首音 → 第二个音）： 于是变换跟着音乐发生（旧版落在“上一句尾音 → 本句首音”的空白里，那段区间没有新音，观感很干）。 所以不会出现“一条还没长完、另一条已经开始”。 转移被激活时不是整条变色，而是彩色沿曲线从起点走到终点，到达终点时箭头才亮起； 同一个音程同时决定三件事：彩色行进走多久、这个点从亮到暗用多久、箭头何时亮 —— 音密处一闪即暗、留白处余韵长（不是每个音都固定时长）。 换句时不是整体外扩，而是给在场节点一次切向抖动，位移沿连线传给邻居： 连线是铰链，弹因此是传开的。力度分两级：换句/段落切换抖得明显， 单个音符发声只是很轻地推一下。段落色逐帧插值，不在句界跳变。
操作：点击画面隐藏 / 显示界面；按 f 全屏、再按一次退出。
与 01 的对照：01 是"从零生成"（和弦进行 + 动机发展）；这里是"记忆 + 重排"—— 音符 100% 来自素材，但顺序被概率重组，听感像"同一首曲子的不同演奏"。
钢琴音色：真实采样 vsco2-piano-mf（VSCO2 免费钢琴库，CC0），经 jsDelivr GitHub 镜像远程加载 （首次约 50MB，之后走浏览器缓存）；加载失败自动回退 FM 合成钢琴，不会卡死。
