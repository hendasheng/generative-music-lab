02 · aisatsana 式极简钢琴

学习 Generative.fm 的 piece-aisatsana：记忆 + 重排的生成方式 —— 音符素材固定（自写的极简琶音）， 但乐句的排列顺序由马尔可夫链重组，每次演奏都不同。
点击播放开始。日志会显示每次乐句转换（马尔可夫链的"行走"）。
机制（对照 aisatsana 源码）：① 音符素材按八分音符网格量化 → ② 每 32 步切成一个乐句 → ③ 乐句序列喂给马尔可夫链训练转换概率 → ④ 演出时 chain.walk() 沿概率生成乐句序列， 每次转换都不同。
与 01 的对照：01 是"从零生成"（和弦进行 + 动机发展）；这里是"记忆 + 重排"—— 音符 100% 来自素材，但顺序被概率重组，听感像"同一首曲子的不同演奏"。
钢琴音色：真实采样 vsco2-piano-mf（VSCO2 免费钢琴库，CC0），经 jsDelivr GitHub 镜像远程加载 （首次约 50MB，之后走浏览器缓存）；加载失败自动回退 FM 合成钢琴，不会卡死。
