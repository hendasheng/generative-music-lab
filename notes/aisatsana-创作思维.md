# 怎么创作"这样的音乐"—— aisatsana 式创作思维

> 配套：`notes/piece-aisatsana-注解版.js`（代码逐行）、`notes/piece-aisatsana-数据说明.md`（素材长什么样）
> 这篇不讲代码，讲**创作方式本身**：你该怎么想、怎么动手。

## 0. 核心观点：先有音乐，再有生成

大多数人以为"生成式音乐 = 写个算法让它作曲"。aisatsana 恰恰相反：

> **先有一段你真心喜欢的音乐，生成器只是"扩展它"的工具。**

作者的创作起点（见他的 Medium 手记）：他喜欢 Aphex Twin 的《aisatsana [102]》，于是问："**我能不能生成更多这种音乐？**"——不是"写个程序随便出声音"，而是"**想让喜欢的音乐更多、每次都不一样**"。

记住这条：**素材是风格的上限，算法只是把素材"讲出新故事"**。

---

## 1. 第一步：选素材（记忆）

- 找一段你真正喜欢的音乐——自己的即兴、写的一段旋律、或一首曲子
- 这段素材决定了**风格、和声、气质**。素材是"记忆"：所有生成的声音 100% 来自它
- aisatsana 的素材：原曲的钢琴谱面（301 秒）。02 练习的素材：手写的 C 大调极简琶音

**创作动作**：拿起琴（或用 DAW 钢琴卷帘）即兴弹 30 秒——不用"创作"，弹你喜欢的、自然流出的东西。

---

## 2. 第二步：把音乐放到网格上（量化）

音乐先被"像素化"成均匀的小格（八分音符 ≈ 0.3 秒一格）：

```
原始音符：E3 @ 0 秒、G3 @ 0.588 秒、C3 @ 1.176 秒 ...
放到网格：格子0: E3 | 格子1: (空) | 格子2: G3 | 格子3: (空) | 格子4: C3 ...
```

**思维工具**：把连续的音乐时间想象成**照片的像素网格**——每个格子记录"这个瞬间有哪些音"。量化后，音乐从"流动的"变成"可编程的"（一堆格子）。

---

## 3. 第三步：切成乐句块（乐高化）

32 个格子 = 一个乐句（约 9 秒）。整段素材被切成**一盒乐高块**：

```
乐句1：E-G-C-C 琶音（安静的开头）
乐句2：E-G-C-C-B（稍亮）
乐句3：...（主题展开）
乐句32：...（收束）
```

**思维工具**：不再以"音符"为单位思考，而以"乐句块"为单位——每块有自己的**性格**（安静的、饱满的、收束的）。音乐 = 一盒有性格的积木。

---

## 4. 第四步：学习衔接规律（语法）

马尔可夫链观察这一盒积木：**它们平时是怎么接的**？

- 安静的开头之后 → 常接主题乐句
- 主题之后 → 常接发展乐句
- 发展之后 → 常回落安静
- 收束之后 → 重新循环

学到的不是音符，而是**"块与块的连接习惯"**——就像学一门语言的造句规则，而不是背单词。

---

## 5. 第五步：重组演出（重排）

演出时，按学到的连接习惯**重新排列乐句块**：

```
这次演奏：乐句1 → 乐句4 → 乐句7 → 乐句2 → 乐句1 ...
下次演奏：乐句2 → 乐句5 → 乐句3 → 乐句8 → 乐句2 ...
```

**音符一个都没变，但顺序每次不同**——所以听起来"是同一首曲子，但每次是不同的版本"。这就是"记忆 + 重排"：**保留素材的语法，改变叙事的顺序**。

---

## 6. 四个思维工具（随手可用）

| 工具 | 一句话 | 怎么用 |
|---|---|---|
| **素材思维** | 先有喜欢的音乐，再有生成 | 别一上来写代码，先弹/找一段素材 |
| **网格思维** | 音乐 = 均匀格子 | 想"这格该有什么音"，而不是"下一个音符"
| **乐句块思维** | 音乐 = 有性格的积木 | 写素材时让每块有"性格"（安静/饱满/收束） |
| **衔接思维** | 音乐 = 块与块的连接习惯 | 观察"什么接什么自然"，让生成沿习惯走 |

---

## 7. 你现在就能做的实践

1. **录一段你自己的 30 秒即兴**（手机录音 / MIDI 键盘 / DAW 钢琴卷帘手写）
2. 把它转成 `{name, time}` 音符列表（DAW 能导出 MIDI→JSON，或手写几个音）
3. 用 02 练习的代码，**换掉 `PHRASES` 用你的素材**（量化 → 切块 → 重组都是现成的）
4. 播放——听"**你的音乐被重新讲述**"

素材越有性格（段落对比、力度起伏），重组后越有段落感——这就是 02 练习乐句库为什么要精心写段落。

---

## 8. 两种生成范式的选择

| 范式 | 例子 | 适合 |
|---|---|---|
| **从零生成** | 01 练习（和弦进行 + 动机发展） | 想要"从来没有过的音乐"，探索未知 |
| **记忆 + 重排** | aisatsana / 02 练习 | 喜欢某段音乐，想要"它的无限版本" |

选择取决于你的目的：**探索新声音用从零生成，深爱某段音乐用记忆重排**。两者也可以结合（重排的素材里混入从零生成的乐句块）。
