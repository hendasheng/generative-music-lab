## Part 2：Developing motivic statements 动机的建立与发展

**Present \-\> Repeat \-\> Big Variation \-\> Deconstruct**

- Present：建立 Motif；
- Repeat：重复，极少的变化或完全不变，强化记忆；
- Variation：保持 Motif 身份的同时加入明显变化；
- Deconstruct：不再完整重复 Motif，而是通过拆解、缩短、留白等，用来结束这个 Present。

### add Variation 添加变化

- Rhythmic Variation 节奏变化
    - 改变起始位置、时值、间隔、休止、重音等；
    - Augmentation：等比例拉长时值；
    - Diminution：等比例缩短时值。

- Melodic Variation 旋律变化：
    - Sequencing 模进：
        - `C - E - G`
        - Chromatic 半音/严格模进：按照音程移动，保留音程关系，可能会出现调外音；
            - `D - F# - A`
        - Diatonic 调内模进：按照当前调移动，保证所有音在当前掉内，实际半音距离可能不同；
            - `D - F - A`

    - Melodic Inversion：音程方向反转，上行 ↔ 下行；

    - Retrograde 逆行：
        - Complete 完全逆行：音高顺序和节奏结构都反转，相当于整个 Motif 从后往前播放；
        - Rhythmic 节奏逆行：反转节奏结构，音高顺序不变；
        - Melodic 旋律逆行：反转音高顺序，节奏结构不变；
    - Fragmentation 碎片化：
        - 将已经建立起来的 Motif 拆成更小的“mini motifs”，选择其中一部分进行重复、删除或修改，从原有材料中发展出新的乐句。

## Part 3： Phrase Structure 乐句结构

Musical Phrase：类似语言中的完整句子，是一个具有开始和结束的、相对完整的旋律。和 Motif 的关系，Musical Phrase 由多个 Motif 构成，具有一定的段落感、完整性。

### 基本结构
**Beginning \-\> Development \-\> End**

### Moon-Motivic Phrase 单动机乐句

围绕一个 Motif 形成 Phrase：
**建立 Motif → 发展 Motif → Local Peak → Ending**

- **Local Peak 局部峰值**：
    - 整个 Phrase 围绕的一个强度目标，可以是相对的高强度点，也可以是低强度点。通常由音高、节奏、和声等多个音乐参数共同形成；
    - Motif 的各种变化应该是朝 Local Peak 推近；
- Ending 结束：
    - 通常在到达 Local Peak 后很快出现；
    - 音乐材料开始离开 Local Peak，不再继续朝 Peak 的方向发展；
        - 最后通过某种 **Musical Punctuation（音乐标点 / 音乐性的句读）**结束 Phrase。

### Poly-Motivic Phrase 多动机乐句
一个 Phrase 使用多个 Motif：
**Motif A → Motif B →（Motif C）→ Ending**

- 建立主要 Motif A；
- Development 发展：
    - 引入新的 Motif B / C，而不是重点发展 Motif A 或朝 Local Peak 推近；
- Ending：
    - 在最后一个 Motif 陈述后，通过 Musical Punctuation 建立结束感。

### Question Phrase / Answer Phrase - 问句 / 答句
- Question：未完成，期待继续；
- Answer：完整、确定、有结束感。

### Musical Punctuation 音乐标点
通过不同音乐参数制造“继续 / 结束”的感觉：
**Melody / Harmony / Rhythm / Texture / Dynamics**

Answer 通常表现为收束，例如旋律下行、音程缩小、节奏放慢、力度降低、织体减少。多个参数同时指向 Answer，结束感越明确。

## Part 4：将旋律转化为曲目

### Mono-Motivic Phrase 的两个基本构件
- **Local Peak**：整个 Phrase 围绕一个目标时刻；
- **Motivic Statements**：Motif 的多次陈述和变化：
    - Beginning / Development：逐渐朝 Local Peak 推进：
    - Ending：到达 Peak 后逐渐离开；

**Motif Statements -> Local Peak -> Move Away**

这种“建立 → 推进 → Peak → 离开”的结构不仅存在于 Phrase，也可以出现在更大的音乐结构层级中。

### Musical Paragraph 音乐段落
多个 Phrase 组成一个 Paragraph，并围绕相似的 Motif / Theme 材料发展。
**Motif -> Phrase -> Paragraph**

- 每个 Phrase 有自己的 Local Peak；
- 多个 Phrase 又共同朝 Paragraph 的 Local Peak 推进，再离开；
- Phrase 之间可以变化，但仍应能听出来自同一核心材料；
- 最后一个 Phrase 通常提供最明确的结束感；
- 当主题材料明显改变时，进入下一个 Paragraph。


### Full Structure 完整结构
整首作品围绕一个整体的 **Climax（高潮 / 全局峰值）**组织。

**Motif -> Phrase -> Paragraph -> Full Piece**

- Phrase：多个 Motif Statements → Local Peak；
- Paragraph：多个 Phrase → 更大的 Local Peak；
- Full Piece：多个 Paragraph → Climax。

也就是说，小层级的 Peak 服务于更大层级的 Peak，最终共同形成整首作品的发展曲线。

因此可以先确定整首作品的 Climax，再反过来安排各个 Paragraph 和 Phrase 如何逐步朝它发展。
